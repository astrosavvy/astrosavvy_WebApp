# Frontend Directory

This folder contains all static user interface files, stylesheet assets, and client-side page integrations.

## Contents

* **`index.html`**: Core testbed dashboard for validating astrological requests.
* **`order.html` / `mobile.html`**: Responsive checkout page forms.
* **`success.html`**: Successful payment confirmation landing page.
* **`love_calculator.html`**: Fun standalone relationship test form.
* **`admin.html` / `admin_login.html`**: Back-office order tracking dashboard views.
* **Assets (`Coverpage.png`, `savvy_singh.jpg`, `favicon.*`)**: Static banner, brand images, and icons.
