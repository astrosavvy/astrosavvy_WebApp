# Backend Directory

This folder houses the core FastAPI server orchestration logic, PDF compiler, payment integrations, and configurations.

## Contents

* **`src/`**: Python source packages.
* **`database/`**: SQL schemas and migration configs.
* **`sample/`**: Astro input configuration examples.
* **`Blank Report Revised.pdf`**: Template base for the overlay engine.
* **`requirements.txt`**: Python third-party dependency file.
* **`package.json` / `package-lock.json`**: Node.js dependencies for PDF-lib.
